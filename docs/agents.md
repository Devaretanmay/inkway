# Agents

An agent is a named worker connected to one coding tool or API provider. Create one with a name, optional description, selected tool/provider, and instructions.

Local CLI agents use their own sign-in. Native API agents use a provider credential saved on the selected runtime. Availability reflects whether the selected tool or provider can run there.

Assign an issue to start work. Follow progress from the issue, then review the summary, changed files, and test results. Accept completed work or reopen it for another attempt.
